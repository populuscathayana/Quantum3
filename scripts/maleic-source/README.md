# 酸酐后处理源码归档

这里保存本次计算审计、结构／频率／轨道图及动画的原始后处理源码，独立于根目录已有乙烯复现流程，避免改变原流程行为。

公开的 `analysis/maleic-*` 文件包含结构、频率、模式、热化学及来源哈希；`experiment-report/figures/maleic-*` 为已审核成品。机器绝对路径已脱敏，科学数值未改。没有上传软件、凭据、调度日志或大型 GBW／CHK／cube 文件。

## 可直接执行的检查

在仓库根目录运行 `python scripts/verify_maleic_publication.py`，仅用 Python 标准库校验发布文件哈希、图片引用和两朝向能垒差，并输出能量比较表，不进行量子计算。

## 源码复现范围

本目录是源码归档，不是独立可一键运行的完整原始计算目录。原始审计程序需要其源码所列的 Gaussian 输出／fchk、ORCA hess／engrad；轨道重绘还需要源 cube，部分渲染脚本导入项目内其他模块。上述大型或未收录原始输入不包含在此更新中，不能只用成品图片重新生成波函数。根目录原有乙烯 `reproduce.py` 的用途保持不变。

最终公开图采用约 8–9 pt 显示字体、简化图内说明并将解释移到报告图注；显示四舍五入不改变 JSON 中的原始数值。最新报告源码与旧 PDF 版本差异见根目录 README。
